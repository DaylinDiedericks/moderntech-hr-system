# ModernTech HR System

## Project Description

ModernTech HR System is a Vue.js and Bootstrap web application that provides a proof-of-concept Human Resources management system for ModernTech Solutions.

The application manages employee information, payroll calculations, leave requests, and attendance records using dummy data.

## Technologies Used

- Vue.js
- Bootstrap 5
- JavaScript
- HTML
- CSS
- Local Storage

## Features

- Employee Management
- Payroll Management
- Digital Payslips
- Leave Requests
- Attendance Tracking
- Responsive Design
- Local Storage

## Setup

1. Clone the repository
2. Run:
   npm install

3. Start development server:
   npm run dev
